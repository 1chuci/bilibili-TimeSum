# Bilibili-TimeSum

一个简洁的网页工具，用于快速计算 Bilibili 视频合集或播放列表的总时长。

在您准备“入坑”一个几十集的学习视频或实况全流程视频之前，用它来估算一下总“肝度”吧！

**[➡️ 在线体验]**(https://bilibili-timesum.pages.dev/)

## ✨ 主要特性

*   **一键计算**：快速计算 B 站视频合集的总时长
*   **智能统计**：显示视频数量、平均时长、最长视频等详细信息
*   **便捷操作**：支持一键清空、复制结果、键盘快捷键
*   **实时验证**：输入时自动验证格式，提供友好的错误提示
*   **响应式设计**：完美适配桌面端和移动端，支持深色模式
*   **安全可靠**：内置输入验证和防护机制，确保使用安全
*   **纯净体验**：纯前端实现，界面现代化，无广告
*   **部署轻松**：静态页面，可以轻松部署在任意静态托管平台

## 🚀 如何使用

### 方法一：使用内置帮助功能（推荐）

1. 打开本工具，点击底部的"**使用帮助**"链接
2. 在弹出的帮助窗口中，点击"**📋 复制代码**"按钮
3. 打开 B 站视频合集页面，按 `F12` 打开开发者工具
4. 点击"控制台"选项卡，粘贴代码并按 `Enter`
5. 复制输出的时长数据，粘贴到本工具中即可

### 方法二：手动复制代码

1. 在浏览器中打开您想要计算的 Bilibili 视频**合集播放页面**
2. 按下 `F12` 键，打开浏览器的"开发者工具"
3. 找到并点击"**控制台**"（Console）选项卡
4. 将下方的代码**完整复制**并粘贴到控制台中，然后按下 `Enter` 键

```javascript
// 这段代码会抓取当前播放列表所有视频的时长
const durations = [...document.querySelectorAll('div.stat-item.duration')].map(el => el.textContent.trim());

// 为了方便复制，我们将其转换为格式化的字符串
console.log(durations.join('\n'));

// 或者直接复制到剪贴板（需要用户授权）
navigator.clipboard.writeText(durations.join('\n')).then(() => {
    console.log('时长数据已复制到剪贴板！');
}).catch(() => {
    console.log('请手动复制上方输出的时长数据');
});
```

5. 控制台会输出所有视频的时长列表，复制这些数据

### 使用计算器

1. 将复制的时长数据粘贴到本工具的文本框中
2. 点击"计算总时长"按钮或按 `Ctrl+Enter` 快速计算
3. 查看详细的计算结果和统计信息
4. 可以点击"📋"按钮复制计算结果

## 🎯 支持的时间格式

- `MM:SS` - 分:秒（如 `07:33`）
- `HH:MM:SS` - 时:分:秒（如 `01:15:15`）
- 自动忽略无效格式的行

## 🛠️ 技术栈

- **前端**：纯 HTML + CSS + JavaScript
- **部署**：静态文件，支持任意静态托管平台
- **兼容性**：支持现代浏览器

## 🌐 浏览器兼容性

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- 需要支持 ES6+ 和 Clipboard API

## 🔧 本地开发

1. 克隆项目到本地
2. 使用任意 HTTP 服务器运行（如 `python -m http.server` 或 VS Code Live Server）
3. 在浏览器中打开 `http://localhost:端口号`

无需安装依赖，直接打开 `index.html` 即可使用（部分功能如剪贴板 API 需要 HTTPS 或 localhost）

## ⚠️ 使用限制

- 单次最多处理 1000 个视频
- 单个视频时长不超过 24 小时
- 输入内容限制 50000 字符
- 计算操作有 100ms 防抖限制

## 🔒 隐私与安全

- 纯前端计算，所有数据在本地处理
- 不收集、不上传任何用户数据
- 不使用 Cookie 或本地存储
- 开源代码，可自行审查

## ❓ 常见问题

**Q: 为什么控制台代码无法提取时长？**
A: Bilibili 页面结构可能已更新。请在视频合集页面（非单个视频页）使用，或手动复制时长数据。

**Q: 支持其他视频网站吗？**
A: 目前仅针对 Bilibili 优化，但支持任何 MM:SS 或 HH:MM:SS 格式的时长数据。

**Q: 计算结果不准确？**
A: 请确保输入格式正确，无效行会被自动忽略。检查是否有格式错误的提示。
